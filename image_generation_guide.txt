## 📐 이미지 크기 조정 방법

### 나노바나나 생성 후 처리:
1. **나노바나나로 생성**: aspect_ratio="1:1"로 생성
2. **CSS로 크기 조정**: 브라우저에서 자동 리사이징 (추천)
   ```css
   .card-image {
       width: 110px;
       height: 110px;
       object-fit: cover;
   }
   ```

3. **외부 도구 사용 (선택사항)**:
   - Python Pillow: `image.resize((200, 200))`
   - 온라인 도구: tinypng.com, squoosh.app 등
