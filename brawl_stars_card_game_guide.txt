================================================================================

게임명: Brawl Cards (가제)
장르: 턴제 카드 배틀러
모드: AI 대전 (초기) → PvP 1대1 (추후)

게임 시간: 7-12분 (평균)

2. 초반 설정 복잡한 부분 & 해결방안
================================================================================

[문제점 1] 카드 데이터 구조 설계
- 문제: 각 카드의 속성을 어떻게 저장하고 관리할지
- 해결: 확장 가능한 구조로 설계
  const cardDatabase = {
    'shelly': {
      id: 'shelly',
      name: '쉘리',
      cost: 3,
      attack: 3,
      health: 4,
      description: '양옆 적에게 산탄 발사!',
      ability: 'battlecry_damage_adjacent',
      abilityValue: 1,
      rarity: 'common',
      image: 'images/brawlers/shelly.png',
      // 추후 확장용 필드
      conditions: null,  // Phase 2에서 추가
      synergies: null,   // Phase 3에서 추가
    }
  }

[문제점 2] 게임 상태 관리
- 문제: 턴, 엘릭서, 손패, 필드, 묘지 등 복잡한 상태 추적
- 해결: 단일 gameState 객체로 통합 관리
  const gameState = {
    turn: 1,
    currentPlayer: 'player',
    player: {
      hp: 25,  // 빠른 게임을 위해 25로 설정
      elixir: 1,
      maxElixir: 1,
      hand: [],
      field: [],  // 최대 7장
      deck: [],
      graveyard: []
    },
    ai: { /* 동일 구조 */ }
  }

[문제점 3] 카드 효과 처리 시스템
- 문제: 다양한 카드 능력을 일관되게 처리
- 해결: 단계별 이벤트 시스템
  Phase 1: 단순 효과만 (onPlay, onDeath)
  Phase 2: 조건부 효과 추가 (if health < 3)
  Phase 3: 연계 효과 추가 (combo, synergy)

[문제점 4] UI/UX 복잡성
- 문제: 드래그&드롭, 타겟팅, 애니메이션 등
- 해결: 
  - Phase 1: 클릭 기반 + 호버 효과
  - Phase 2: 타겟팅 화살표
  - Phase 3: 드래그&드롭

[문제점 5] 밸런싱
- 문제: 카드 간 밸런스
- 해결: 
  - 기본 공식: (공격력 + 체력) / 비용 = 2.0~2.3
  - 능력 있으면 스탯 -1
  - AI 테스트로 승률 체크

5. 게임 진행 규칙
================================================================================

【게임 설정】
- 플레이어 HP: 25
- 초기 손패: 3장 (선공) / 4장 (후공)
- 덱 크기: 20장 (같은 카드 최대 2장)

- 자신 HP 0 이하: 패배
- 동시 0: 무승부

- 도발: 우선 공격 대상
- 돌진: 즉시 공격 가능

- 플레이 시: 카드 사용 즉시 발동
- 사망 시: 파괴될 때 발동

6. AI 시스템 설계
================================================================================

【중급 난이도 AI - "스마트 브롤러"】

행동 우선순위:
1. 치명적 위협 제거 (다음 턴 패배 방지)
2. 유리한 교환 (비용 대비 가치)
3. 보드 컨트롤 유지
4. 효율적인 엘릭서 사용

AI 로직:
```javascript
function aiTurn() {
  // 1. 상황 평가
  const threat = evaluateThreat();
  const boardState = evaluateBoard();
  
  // 2. 최적 플레이 계산
  const possiblePlays = calculatePlays();
  const bestPlay = possiblePlays.sort((a, b) => 
    b.value - a.value
  )[0];
  
  // 3. 20% 확률로 차선책 선택 (실수 시뮬레이션)
  if (Math.random() < 0.2) {
    return possiblePlays[1] || bestPlay;
  }
  
  return bestPlay;
}
```

난이도 특징:
- 기본 전략 이해
- 가끔 실수 (20%)
- 콤보는 못 봄
- 2수 앞까지만 계산

## 🃏 브롤스타즈 카드게임 전용 규칙

├── index.html

│   ├── style.css

### 코드 작성 원칙
- 카드 추가는 cards.js의 cardDatabase에만
- 새 능력은 effects.js의 abilityHandlers에 추가
- 모든 상태 변경은 updateGameState() 통해서
- Phase별로 기능 분리 (주석으로 표시)

### 카드 데이터 표준
