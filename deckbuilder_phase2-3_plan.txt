  - 서포터 (8종): 게일의 보급, 타라의 포탈, 크로우의 독, 스튜의 전략, 프랭크의 방어, 맥스의 돌격, 진의 재활용, 스파이크의 재생
- **총 카드 풀: 31종**

## 🎯 덱 빌더 규칙

### 기본 규칙
1. **덱 크기**: 정확히 20장
2. **동일 카드 제한**: 최대 2장 (트리플은 불가)
3. **기본 브롤러 필수**: 최소 1장 이상 포함 (진화 카드만으로는 불가)
4. **진화 카드**: 기본 브롤러 없이 진화 카드만 넣을 수 없음 (예: Shelly 없이 Bandita Shelly만 넣기 불가)
5. **토큰 카드**: 덱에 포함 불가 (Bruce, Scrappy, Old Lobber)

### 유효성 검증 체크리스트
- [ ] 총 20장 정확히 구성
- [ ] 동일 카드 2장 이하
- [ ] 기본 브롤러 최소 1장 포함
- [ ] 진화 카드가 있으면 해당 기본 브롤러도 포함
- [ ] 토큰 카드 미포함

## 🛠 기술 스택

### deckbuilder.js (신규)

**IIFE 패턴:**
```javascript
(function() {
    'use strict';

    const DEBUG = true;
    const MAX_DECK_SIZE = 20;
    const MAX_CARD_COPIES = 2;
    const STORAGE_KEY = 'brawl_tcg_deck';

    // 덱 빌더 객체
    const DeckBuilder = {
        currentDeck: [],  // 현재 구성 중인 덱 [{id, count}, ...]

        // 덱 초기화
        init: function() { ... },

        // 카드 추가
        addCard: function(cardId) { ... },

        // 카드 제거
        removeCard: function(cardId) { ... },

        // 덱 유효성 검증
        validateDeck: function(deck) {
            // 20장 체크
            // 동일 카드 2장 이하 체크
            // 기본 브롤러 포함 체크
            // 진화 카드 기본 브롤러 의존성 체크
            return { valid: true/false, errors: [] };
        },

        // localStorage 저장
        saveDeck: function(deckName) {
            const deckArray = this.convertToArray(this.currentDeck);
            localStorage.setItem(STORAGE_KEY + '_' + deckName, JSON.stringify(deckArray));
        },

        // localStorage 불러오기
        loadDeck: function(deckName) {
            const data = localStorage.getItem(STORAGE_KEY + '_' + deckName);
            if (data) {
                const deckArray = JSON.parse(data);
                this.currentDeck = this.convertToDeckObject(deckArray);
                return deckArray;
            }
            return null;
        },

        // 덱 목록 가져오기
        listDecks: function() {
            const keys = Object.keys(localStorage);
            return keys.filter(k => k.startsWith(STORAGE_KEY));
        },

        // 덱 객체 → 배열 변환 (game.js 호환)
        convertToArray: function(deckObject) {
            const deck = [];
            deckObject.forEach(item => {
                for (let i = 0; i < item.count; i++) {
                    deck.push(window.CardDB.get(item.id));
                }
            });
            return deck;
        },

        // 배열 → 덱 객체 변환
        convertToDeckObject: function(deckArray) {
            const deckMap = {};
            deckArray.forEach(card => {
                if (!deckMap[card.id]) {
                    deckMap[card.id] = { id: card.id, count: 0 };
                }
                deckMap[card.id].count++;
            });
            return Object.values(deckMap);
        },

        // 프리셋 덱 반환
        getPreset: function(presetName) {
            const presets = {
                'balanced': [
                    {id: 'shelly', count: 2},
                    {id: 'bandita_shelly', count: 1},
                    {id: 'colt', count: 2},
                    {id: 'nita', count: 2},
                    {id: 'poco', count: 2},
                    {id: 'bull', count: 1},
                    {id: 'super_potion', count: 2},
                    {id: 'brawl_ball', count: 2},
                    {id: 'brawl_box', count: 2},
                    {id: 'gales_supply', count: 2},
                    {id: 'taras_portal', count: 1},
                    {id: 'crows_poison', count: 1}
                ],
                'aggro': [
                    {id: 'shelly', count: 2},
                    {id: 'bandita_shelly', count: 2},
                    {id: 'edgar', count: 2},
                    {id: 'bibi', count: 2},
                    {id: 'bull', count: 2},
                    {id: 'maxs_rush', count: 2},
                    {id: 'power_cube', count: 2},
                    {id: 'instant_switch', count: 2},
                    {id: 'crows_poison', count: 2},
                    {id: 'brawl_box', count: 2}
                ],
                'control': [
                    {id: 'poco', count: 2},
                    {id: 'serenade_poco', count: 2},
                    {id: 'byron', count: 2},
                    {id: 'piper', count: 2},
                    {id: 'jessie', count: 1},
                    {id: 'penny', count: 1},
                    {id: 'super_potion', count: 2},
                    {id: 'spikes_regen', count: 2},
                    {id: 'franks_defense', count: 2},
                    {id: 'shield_gear', count: 2},
                    {id: 'taras_portal', count: 2}
                ]
            };
            return presets[presetName] || null;
        }
    };

    // 전역 노출
    window.DeckBuilder = DeckBuilder;

})();
```

3. 여러 덱을 저장하여 다양한 전략 실험

## 🐛 예상 이슈 및 해결책

### 이슈 1: localStorage 용량 제한
- **문제**: localStorage는 5-10MB 제한
- **해결**: JSON 압축, 오래된 덱 자동 삭제 (최대 10개 보관)

### 이슈 2: 진화 카드 의존성 검증
- **문제**: Bandita Shelly만 있고 Shelly 없는 경우
- **해결**: validateDeck에서 진화 카드의 evolvesFrom 체크

### 이슈 3: 모바일 대응
- **문제**: 작은 화면에서 UI 표시 어려움
- **해결**: 반응형 CSS, 카드 그리드 자동 조정

### 이슈 4: 덱 초기화 버그
- **문제**: 덱 빌더에서 게임으로 전환 시 덱 미적용
- **해결**: game.js의 initGame()에서 DeckBuilder.loadDeck() 호출 확인
