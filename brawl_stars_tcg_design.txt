Pokemon TCG Pocket 기반 카드 배틀 게임
========================================

📅 작성일: 2025-10-10
🎮 프로젝트명: Brawl Stars TCG
🎯 Phase 1: 기본 전투 시스템 + 초기 카드 풀

========================================
1. 게임 개요
========================================

- 장르: 1v1 턴제 카드 배틀 게임
- 참고 게임: Pokemon TCG Pocket (모바일)
- 플랫폼: PC 브라우저 (Chrome, Firefox, Edge)
- 기술 스택: HTML5, CSS3, Vanilla JavaScript ES6+
- 덱 크기: 20장
- 승리 조건: 상대 브롤러를 쓰러뜨려 3점 먼저 획득

========================================
2. 핵심 시스템
========================================

2.1 에너지 시스템
-----------------
- 타입: 🔷 브롤 에너지 (단일 타입)
- 생성: 매 턴 자동으로 랜덤 1개 생성 (선공 1턴 제외)
- 부착: 플레이어가 생성된 에너지를 원하는 브롤러에 수동 부착 (턴당 1회)
- 지속성: 부착된 에너지는 소모되지 않고 유지 (특정 공격 제외)
- 표기:
  - 🔷 = 브롤 에너지
  - ⚪ = 무색 (어떤 에너지로도 지불 가능)

2.2 필드 구조
-----------------
- 배틀존: 1개 (공격 가능한 활성 브롤러)
- 벤치: 3개 (대기 중인 브롤러)
- 손패: 최대 제한 없음
- 덱: 20장
- 에너지존: 생성된 에너지 임시 보관

2.3 덱 구성
-----------------
- 총 20장
- 브롤러 카드: 약 10장 (기본 + 진화)
- 트레이너 카드: 약 10장 (아이템 + 서포터)
- 동일 카드 최대 2장

2.4 브롤러 등급 시스템
-----------------
| 등급 | 처치 점수 | 진화 후 점수 |
|------|----------|-------------|
| 기본 | 1점 | 2점 |
| 희귀 | 1점 | 2점 |
| 초희귀 | 1점 | 2점 |
| 영웅 | 1점 | 2점 |
| 신화 | 2점 | 2점 |
| 전설 | 2점 | 2점 |
| 울트라전설 | 2점 | 2점 |

========================================
3. 게임 플로우
========================================

3.1 게임 시작
-----------------
1. 각 플레이어 20장 덱 구성
2. 덱 셔플 (Fisher-Yates)
3. 동전 던지기로 선공 결정
4. 5장 드로우 (기본 브롤러 1장 보장)
5. 기본 브롤러 1장을 배틀존에 배치
6. 추가 기본 브롤러는 벤치에 배치 가능

3.2 턴 진행
-----------------
1. 카드 드로우 (1장) - 선공 1턴 제외
2. 에너지 자동 생성 (1개) - 선공 1턴 제외
3. 액션 단계 (순서 자유):
   a. 에너지 부착 (턴당 1회)
   b. 브롤러 진화 (첫 턴 or 배치한 턴 제외)
   c. 벤치에 기본 브롤러 배치
   d. 아이템 사용 (무제한)
   e. 서포터 사용 (턴당 1회)
   f. 브롤러 후퇴 (배틀존 ↔ 벤치)
   g. 공격 (턴 종료)
4. 턴 종료

3.3 승리 조건
-----------------
- 상대 브롤러를 쓰러뜨려 3점 먼저 획득
- 기본~영웅 브롤러: 1점 (진화 시 2점)
- 신화~울트라전설: 2점 (진화 시 2점 유지)

========================================
4. 카드 시스템
========================================

4.1 브롤러 카드
-----------------
구조:
- id: 고유 식별자
- name: 브롤러 이름
- rarity: 등급 (common, rare, super_rare, epic, mythic, legendary, ultra_legendary)
- hp: 체력 (10~100 단위)
- retreatCost: 후퇴 비용 (🔷 개수)
- attacks: 공격 배열
  - name: 공격 이름
  - cost: 에너지 비용 ([🔷, ⚪] 형식)
  - damage: 피해량
  - energyDiscard: 사용 후 버릴 에너지 개수 (선택)
  - effect: 특수 효과 (선택)
- evolvesTo: 진화 대상 (선택)
- evolvesFrom: 진화 전 브롤러 (진화 카드인 경우)
- isBasic: 기본 브롤러 여부

4.2 트레이너 카드
-----------------
구조:
- id: 고유 식별자
- name: 카드 이름
- type: 'item' 또는 'supporter'
- effect: 효과 함수

타입:
- item: 턴당 무제한 사용
- supporter: 턴당 1회만 사용

========================================
6. 진화 시스템
========================================

6.1 진화 조건
-----------------
- 손에 진화 카드가 있어야 함
- 해당 기본 브롤러가 배틀존 또는 벤치에 있어야 함
- 첫 턴에는 진화 불가
- 필드에 나온 턴에는 진화 불가
- 진화 카드를 손에서 사용하여 기본 브롤러 위에 올림

6.2 진화 효과
-----------------
- HP 증가
- 공격력/공격 종류 변경
- 후퇴 비용 유지 또는 변경
- 부착된 에너지 유지
- 상태 이상 제거

6.3 스킨 진화 방식
-----------------
- Shelly → Bandita Shelly (스킨 변경)
- Colt → Royal Agent Colt (스킨 변경)
- Poco → Serenade Poco (스킨 변경)

========================================
7. 후퇴 시스템
========================================

7.1 후퇴 규칙
-----------------
- 배틀존 브롤러를 벤치로 이동 가능
- 후퇴 비용만큼 에너지 버려야 함
- 벤치가 가득 차면 후퇴 불가
- 후퇴 후 벤치 브롤러 1명을 배틀존으로 이동
- 턴당 제한 없음 (에너지만 충분하면 가능)

7.2 후퇴 비용
-----------------
- Shelly: 🔷 (1개)
- Colt: 🔷 (1개)
- Nita: 🔷🔷 (2개)
- Poco: 🔷 (1개)
- Bull: 🔷🔷🔷 (3개)

8. AI 시스템

-----------------

8.2 AI 우선순위
-----------------

2. 상대 브롤러 처치 가능하면 공격
3. 진화 가능하면 진화
4. 에너지 부착 (가장 강한 브롤러에게)
5. 트레이너 카드 사용 (효율적인 타이밍)
6. 공격 (가장 피해 큰 공격 선택)
7. 20% 확률로 랜덤 실수

10. Phase 1 목표
========================================

✅ 구현 기능:
1. 카드 데이터베이스 (브롤러 5종 + 진화 + 트레이너 6종)
